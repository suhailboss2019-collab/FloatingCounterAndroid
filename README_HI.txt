FLOATING COUNTER - ANDROID SOURCE PROJECT

Yeh Android Studio project hai; ready-made APK nahi hai.

APK banane ka tarika:
1. Android Studio install karein.
2. Is ZIP ko extract karke Android Studio me project open karein.
3. Gradle sync hone dein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) par click karein.
5. App phone me install karein.
6. App kholkar "Show floating counter" dabayein.
7. Android ki "Display over other apps" permission allow karein.
8. Blue bubble ko tap karne par count +1 hoga. Bubble ko drag karke jagah badal sakte hain.
9. Count app ke local storage me save hota hai. "Hide floating counter" se bubble band hoga.

Note:
- Android 13+ par notification permission prompt aa sakta hai.
- Android/phone manufacturer background-service restrictions ki wajah se kabhi-kabhi service ko manually allow karna pad sakta hai.
- App ko uninstall ya app data clear karne par saved count mit jayega.
